# Code of Conduct

qc-use follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be kind and patient. Assume good intent.
- Give and accept feedback about the work, not the person.
- Harassment, insults, and personal attacks are not accepted in any project space.

## Report a problem

Send a private message to the maintainer, [@aadilghani1](https://github.com/aadilghani1), on GitHub. We keep every report private. We answer within 7 days.

The maintainer can remove comments, commits, and issues, and can ban a person from the project, for behavior that breaks this code.
