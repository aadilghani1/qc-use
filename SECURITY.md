# Security

Please do not report a security problem in a public issue.

Report it privately with a GitHub security advisory: open the **Security** tab of this repository and click **Report a vulnerability**. Tell us what you found, how to reproduce it, and what can go wrong.

We answer within 7 days.

Examples of security problems:

- A secret value reaches a model, a report, a trace, or a screenshot.
- Page content makes qc-use leave the allowed sites or skip the never-do gate.
- The live view (`--watch`) shows data to another user or program on the machine.
